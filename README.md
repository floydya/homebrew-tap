# Homebrew tap for vlt

Install the official Vault CLI and `vlt` on macOS:

```console
brew tap hashicorp/tap
brew install hashicorp/tap/vault
brew install floydya/tap/vlt
```

The `vlt` formula builds tagged source from [`floydya/vlt`](https://github.com/floydya/vlt). Vault remains a separate prerequisite.
